Privacy Policy

This Privacy Policy explains how SNS Analyst Agent handles data when used as a local TikTok analytics tool.

Data the tool may access

With the user's authorization through TikTok Login Kit, the tool may access the following information depending on approved scopes:

  • Basic TikTok profile information such as open ID, avatar, and display name.
  • Profile fields such as bio description, profile links, and verification status.
  • Account summary statistics such as follower count, following count, likes count, and video count.
  • Public video metadata such as video ID, title, description, create time, duration, cover image URL, share URL, embed link, view count, like count, comment count, and share count.

Local storage

The tool stores fetched data locally on the user's computer as JSON, CSV, token, and Markdown report files. The project does not operate a hosted backend service that collects TikTok account data.

Third-party sharing

The tool does not automatically send TikTok data to third-party services. If the user explicitly enables an optional external LLM provider, selected local summary data may be sent to that provider for report generation according to the user's configuration and that provider's terms.

Token handling

OAuth access and refresh tokens are saved locally when the user chooses to store them. Users can delete the local token file at any time to remove local access credentials.

Data deletion

Users control local files created by the tool and may delete generated JSON, CSV, token, and report files from their computer at any time.

Contact

If this tool is published as a GitHub repository, issues and privacy questions can be submitted through the repository's issue tracker.
