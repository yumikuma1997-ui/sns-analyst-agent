SNS Analyst Agent

Local TikTok analytics for your own public videos.

Terms of Service Privacy Policy

What this tool does

SNS Analyst Agent is a local desktop/CLI tool for analyzing the authenticated user's own public TikTok videos using official TikTok APIs. It retrieves authorized public video metadata and engagement counts, saves the data locally as JSON/CSV, and generates a local Markdown analytics report.

The tool is intended for personal account improvement, content planning, and KPI review.

Official API use

  • Login Kit is used only for user authorization.
  • User Info API is used to read the authenticated user's profile and account summary fields when authorized.
  • Video List API is used to read the authenticated user's public video metadata and public engagement counts.

What this tool does not do

  • It does not scrape TikTok.
  • It does not automate login or browser navigation.
  • It does not post videos or comments.
  • It does not perform likes, follows, comments, or other engagement actions.
  • It does not buy followers, inflate views, or provide guaranteed growth claims.

Data storage

Data fetched by the tool is stored locally on the user's computer. The project does not operate a hosted backend service for collecting TikTok account data.
